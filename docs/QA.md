# 网页与发布验收

本地 Chrome 自动化验收通过，桌面 1440px、手机触屏模拟 390px；另外检查 320 / 390 / 1024 / 1440px 无横向溢出。截图检查真实照片裁切、文字清晰度与 Bento 布局。

- 原位放大：点击打开、下一张、缩放与还原、Esc 关闭、关闭按钮归位；横向拖动切换图片。
- 触屏：真实 touch 事件左滑切图、touchCancel 后解除拖动、下滑关闭；触屏点按展开手风琴。
- 滚动揭幕：点击向下探索后 scrollTop 增长，图片展开到完整；重置返回顶部。
- 筛选重排：快速依次切换山川 / 森林 / 海岸 / 全部 / 山川，最终显示 3 张正确分类；重置恢复 6 张。
- 像素换图：波浪、圆形、随机各执行一次，标题及底图更新，按钮恢复可用；转场中离开页签会结束在途动画。
- 手风琴：点击与方向键改变展开面板；每次只有一个 aria-expanded=true。
- 通用：完整提示词复制、页签 Home/End/方向键、切换清理、重置。
- 减少动态效果：放大/关闭直接切换，滚动图片直接展示，像素换图直接替换。
- 页面资源请求与脚本异常：0。

影片检查见 [FILM-QA.md](FILM-QA.md)。同一套网页用例用于发布后的线上复查；线上另检查视频原速播放到结束、3/10/16/19 秒跳转及源码 ZIP 可下载。

网页交付版在保留 1080p / 60fps / 20 秒与 AAC 音轨的前提下压缩至约 7.5 MB；本地原片保留。源码 ZIP 去掉重复视频与可再生音轨，包含网页和影片源代码、照片、字体及预览缩略图。
